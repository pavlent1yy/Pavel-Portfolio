# CLAUDE.md

Лендинг-портфолио Павла Хухарева (Java backend-разработчик): главная страница и отдельная страница проектов. Аудитория — в первую очередь заказчики с фриланс-бирж, во вторую — работодатели, в основном не технические люди. Исходное ТЗ: `prompt.md`, правки: `edits.md`, референсы: `1.png`, `2.png`.

## Команды

```bash
npm run dev      # http://localhost:3000, редиректит на /ru или /en
npm run build    # статическая сборка /ru, /en, /ru/projects, /en/projects
npm run lint
npx tsc --noEmit
```

Тестов нет.

## Стек

Next.js 16 (App Router, React 19, React Compiler), TypeScript, CSS Modules без Tailwind, иконки технологий из `simple-icons` (CC0). Документация Next 16 лежит в `node_modules/next/dist/docs/`, сверяйся с ней: API отличается от старых версий (например, `middleware.ts` переименован в `proxy.ts`, хелперы `PageProps<"/[lang]">` / `LayoutProps` глобальные).

## Структура

- `src/app/[lang]/layout.tsx`: корневой layout (html/body, шрифты, inline-скрипт темы), `generateStaticParams` для ru/en
- `src/app/[lang]/page.tsx`: главная; `src/app/[lang]/projects/page.tsx`: страница проектов
- `src/proxy.ts`: выбор языка для путей без префикса
- `src/i18n/`: `config.ts` (локали, страны и языки СНГ), `ui.ts` (тексты интерфейса), `dictionaries.ts`
- `src/content/`: `types.ts` (`Text`, `todo()`), `ru.ts` и `en.ts` (наполнение)
- `src/config/site.ts`: имя, контакты, часовой пояс, ссылка на резюме (пустая — кнопка-заглушка)
- `src/config/mascot.ts`: позы маскота, пути к фото, `cueMascot()`
- `src/components/`: `Section`, `HandNote`, `T`, `Tech` (шильдики), `Landscape` (SVG-пейзаж в hero), `Mascot` + `MascotFace` (заглушки поз), `ResumeButton`, `ThemeToggle`; `sections/`: секции главной; `projects/`: страница проектов и режимы текста
- `public/fonts/`: рукописные шрифты автора из его проекта Spectfaker
- `public/images/projects/`: скриншоты из репозиториев автора (WebP)

## Правила наполнения (важно)

- Весь текст на сайте пишет автор, не Claude. Claude только оставляет подсказки и задаёт вопросы, которые могут возникнуть у заказчиков.
- Подсказка оформляется как `todo("Тут напиши про X")` / `todo("Тут расскажи про Y")`. Компонент `T` рендерит её пунктирным подчёркиванием с карандашом. Автор заменяет `todo("…")` строкой.
- Можно и нужно исправлять фактические, логические и орфографические ошибки в текстах автора.
- Тексты интерфейса (меню, кнопки, подписи) живут в `src/i18n/ui.ts`.
- `en.ts` пока равен `ru.ts`: перевод делается после заполнения русской версии.
- Подробная памятка для автора: `CONTENT.md`.

## Язык

- Пути `/ru` и `/en`. `proxy.ts` редиректит пути без префикса по порядку: cookie `lang`, затем гео-заголовок (`x-vercel-ip-country` / `cf-ipcountry`: СНГ → ru, иначе en), затем первый язык из `Accept-Language`, по умолчанию ru.
- Кнопка переключения в шапке (`LangSwitch`) пишет cookie `lang`, сохраняет текущую страницу и якорь.

## Тема

- Две темы: светлая по умолчанию и тёмная, обе намеренно неконтрастные. Системная настройка не учитывается.
- `data-theme` на `<html>`, выбор в cookie `theme`, inline-скрипт в начале `<body>` (через `dangerouslySetInnerHTML` на `<div hidden>`, чтобы React 19 не ругался на `<script>` в компоненте) применяет его до отрисовки (страницы остаются статическими).
- Палитра тёплая: песочный, коричневый, янтарь (`#e3a568`) и тёплые серые. Все цвета — токены в `src/app/globals.css`, включая цвета пейзажа (`--sky-horizon`, `--far`, `--mid`, `--near`, `--ink`, `--led`…). Новых цветов вне токенов не заводить (исключение — фиксированные цвета кожи и таблички маскота).
- Переключатель темы: в покое солнце/луна, при наведении лампочка (горит в светлой, погашена в тёмной).

## Маскот

- Фото автора в правом нижнем углу (`Mascot`), реагирует на действия. Позы: `idle`, `curious` → `pointing` (наведение), `rubEyes` / `squint` (смена темы), `laptop` (зона проектов), `book` (вопросы), `joy` (резюме), `sign` (контакты, табличка с текстом из `content.mascot.sign`), `stare` → `peace` → исчезновение (клик).
- Зоны задаются атрибутом `data-mascot-zone` (проп `zone` у `Section`), реакции на наведение — `data-mascot="pose"` на любом элементе, программно — `cueMascot(pose, ms)`.
- Пока фото нет, рисуются SVG-заглушки из `MascotFace`. Фото подключаются в `mascotPhotos`.

## Страница проектов

- Каждый проект в `content.projects.items` имеет `summary` (для главной), `human[]` и `tech[]` (два стиля рассказа), `shots[]`.
- Переключатель «По-человечески / По-айтишному» (`projects/Mode.tsx`) перепечатывает текст побуквенно, как LLM; технический режим набран JetBrains Mono. Высота абзацев не прыгает за счёт невидимой копии текста.

## Дизайн

- Шрифты: Onest (всё), JetBrains Mono (только технический режим на странице проектов), «Pavel Hand» (почерк автора, только в `HandNote`).
- Hero: текст сверху, ниже SVG-пейзаж (дюны, плато, серверный домик, вышка, git-дерево, человечек с ноутбуком), днём солнце, ночью луна и звёзды.
- Всё выровнено по левому краю. Секции: заголовок слева и контент справа (`layout="split"`) или друг под другом (`layout="stack"`).
- Кнопки (`.btn`, `.btn-primary`, `.btn-ghost`, `.btn-small`) автору нравятся, стиль не менять.
- Анимация только одна: появление hero и прорисовка стрелки у заметки. Плюс отклик на действия (аккордеон, смена темы, маскот, печать текста). Уважать `prefers-reduced-motion`.
- Избегать шаблонных приёмов: КАПС-надписи над заголовками, нумерация там, где нет последовательности, одинаковые карточки с тенями, стрелка «→» в ссылках.

## Прочее

- `{age}` в любой строке контента: компонент `T` подставляет `Age` (возраст от `site.birthDate` со склонением; в HTML — на дату сборки `BUILD_TIME` из `next.config.ts`, в браузере пересчитывается).
- Иконки соцсетей в hero: `site.presence` + `site.contacts[id].url`; пустой url — иконка скрыта. Живой онлайн-статус Telegram отложен.
- Карусель проектов на главной (`sections/ProjectCarousel.tsx`): порядок из `projects.items`, 5 с на карточку, таймер — CSS-анимация полоски прогресса; пауза при наведении/фокусе и вне экрана, клик выключает автопрокрутку, при reduced motion автопрокрутки нет.
- Иконки шильдиков (`Tech.tsx`): точное совпадение, затем поиск ключевого слова в строке, затем общие иконки (`generic`).
- Скрипт темы лежит в `src/config/theme.ts` и используется в `[lang]/layout.tsx` и `app/global-not-found.tsx` (404 для несуществующих путей, флаг `experimental.globalNotFound`).
- SEO: `metadataBase` из `site.url` (на Vercel `VERCEL_PROJECT_PRODUCTION_URL`), hreflang в `generateMetadata`, `app/sitemap.ts`, `app/robots.ts`, OG-картинка `[lang]/opengraph-image.tsx` (шрифт Onest из `@fontsource/onest`).
- Список открытых задач по сайту: `TODO.md`.
- Навигация до 1080 px: бургер `MobileNav` в шапке (ссылки те же, что в `nav`). Маскот показывается только на ПК: `(min-width: 1081px) and (hover: hover)`, иначе `Mascot` возвращает `null` (фото не грузятся).
