чтобы его спокойно мог прочитать даже человек не из IT.

## Возможности

На текущем этапе сайт включает:

- главную страницу: обо мне, проекты, роудмап, вопросы и контакты;
- отдельную страницу с подробным рассказом про каждый проект;
- переключатель «По-человечески / По-айтишному» — один и тот же проект описан для заказчика и для разработчика
- карусель проектов на главной: каждая карточка открыта 5 секунд, потом сворачивается и уступает место следующей;
- два языка: русский и английский, с автоматическим выбором;
- две темы: «темноватую» и «светловатую» — ночью не слепит, на солнце читается;
- маскота в углу экрана, который реагирует на то, что происходит на странице;

## Архитектура

Все страницы собираются заранее как статические. Сервер ничего не рендерит на лету,
поэтому сайт открывается быстро и не нагружает хостинг.

### Выбор языка

Пути без языкового префикса перехватывает `proxy.ts`и редиректит по следующему порядку:

```text
Пользователь открывает /
        ↓
cookie lang (уже выбирал язык вручную?)
        ↓
страна по гео-заголовку хостинга (СНГ → ru, иначе en)
        ↓
первый язык из Accept-Language
        ↓
ru по умолчанию
        ↓
/ru или /en
```

Ручной выбор кнопкой в шапке сохраняется в cookie и всегда побеждает автоматику.

### Тема

Выбранная тема хранится в cookie `theme`. Маленький inline-скрипт в начале `<body>`
применяет её ещё до первой отрисовки, поэтому страница не мигает светлой темой
перед тёмной. Страницы при этом остаются статическими.

### Контент отдельно от вёрстки

Весь текст сайта лежит в `src/content/`, а не в компонентах:

```text
ru.ts / en.ts
     ↓
dictionaries.ts
     ↓
page.tsx
     ↓
секции и компоненты
```

Тексты интерфейса (меню, кнопки, подписи) живут отдельно в `src/i18n/ui.ts`.
Такое разделение позволяет поправить текст или добавить язык, не трогая компоненты.

Пара мелочей в формате контента:

- `todo("Тут расскажи про X")` — подсказка вместо ненаписанного текста, на сайте подсвечивается пунктиром;
- `{age}` внутри строки — подставляется текущий возраст со склонением («19 лет», «21 год»).

## Структура проекта

```text
src/
├── app/
│   ├── globals.css          токены цветов, шрифтов и отступов для обеих тем
│   └── [lang]/
│       ├── layout.tsx       html/body, шрифты, скрипт темы
│       ├── page.tsx         главная
│       └── projects/        страница проектов
├── proxy.ts                 выбор языка для путей без префикса
├── i18n/                    локали, страны СНГ, тексты интерфейса
├── content/                 наполнение сайта (ru.ts, en.ts, типы)
├── config/
│   ├── site.ts              имя, контакты, часовой пояс, дата рождения
│   └── mascot.ts            позы маскота
└── components/
    ├── sections/            секции главной: Hero, About, Projects, Roadmap, Faq, Contact
    ├── projects/            страница проектов и переключатель стиля рассказа
    ├── Landscape.tsx        SVG-пейзаж в hero (день/ночь)
    ├── HandNote.tsx         заметки моим почерком
    ├── Tech.tsx             шильдики технологий с иконками
    └── Mascot.tsx           маскот

public/
├── fonts/                   рукописные шрифты из Spectfaker
└── images/projects/         скриншоты проектов (WebP)
```

## 🚀 Запуск

Нужны: Node.js 20+ и npm

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000 и сразу перекинет на `/ru` или `/en`.

Сборка и проверки:

```bash
npm run build
npm run lint
npx tsc --noEmit
```
